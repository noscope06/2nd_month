## GitHub Pages
1. Create a new GitHub repository.
2. Upload **`index.html` and the entire `assets` folder** (do not upload only the HTML).
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

Important: keep the folder structure exactly as supplied:
`index.html`
`assets/photo files`
`assets/a-thousand-years.mp3`

The audio file is included because it was supplied in this conversation. Make sure your use of the music is permitted by the relevant rights holder/platform before publishing it publicly.
